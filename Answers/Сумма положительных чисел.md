## 1. Условие задачи

Дан список целых чисел. Необходимо найти сумму только положительных чисел.

## 2. Объяснение решения

Для решения задачи необходимо:

1. Создать список чисел.
    
2. Создать переменную для хранения суммы.
    
3. Перебрать все элементы списка.
    
4. Проверить каждый элемент на положительность.
    
5. Если число положительное, добавить его к сумме.
    

## 3. Связь с другими темами

[[Числовые типы данных]] помогают выбрать тип переменной для хранения чисел и суммы. В данном случае используется `int`.

[[Условный оператор]] позволяет проверить, является ли число положительным.

[[Циклы]] позволяют перебрать все элементы списка.

Общий термин [[Цикл]] объясняет принцип повторения действий и помогает понять работу цикла в этой задаче.

## 4. Пример решения

```
numbers = [3, -2, 0, 5]

total = 0

for number in numbers:
    if number > 0:
        total += number

print(total)
```

Результат:

```
8
```

## 5. Проверка результата

Положительные числа в списке: 3 и 5.

Отрицательное число -2 и ноль не учитываются.

Итоговая сумма:

3 + 5 = 8.

Если список не содержит положительных чисел, результат будет равен 0.

## 6. Дополнительный пример

```
numbers = [-5, -2, 0]

total = 0

for number in numbers:
    if number > 0:
        total += number

print(total)
```

Результат:

```
0
```

## 7. Вывод

Для решения задачи используются числовые типы данных, условный оператор и цикл. Их совместное применение позволяет перебрать список и сложить только положительные значения.
