## 1. Определение

Числовые типы данных используются для хранения чисел и выполнения математических операций.

В Python основными числовыми типами являются:

- `int` — целые числа.
    
- `float` — вещественные числа.
    
- `complex` — комплексные числа.
    

## 2. Особенности

Тип `int` применяется для хранения целых значений, например количества предметов или количества учеников.

Тип `float` используется для дробных значений, например цены товара или результата деления.

## 3. Пример

```
students = 25
price = 15.75

print(students)
print(price)
```

Результат:

```
25
15.75
```

При решении математических задач правильный выбор типа помогает избежать ошибок при вычислениях.

## 5. Вывод

Числовые типы данных позволяют хранить и обрабатывать числовую информацию. При выборе типа необходимо учитывать характер значения и требуемую точность.
