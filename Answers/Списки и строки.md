## 1. Списки

Список — это структура данных, которая позволяет хранить несколько значений в одной переменной.

В Python список создаётся с помощью квадратных скобок.

Пример:

```
numbers = [10, 20, 30, 40]

print(numbers)
print(numbers[0])
```

Результат:

```
[10, 20, 30, 40]
10
```

## 2. Строки

Строка — это последовательность символов, которая используется для хранения текста.

Строки создаются с помощью одинарных или двойных кавычек.

Пример:

```
name = "Python"

print(name)
print(name[0])
```

Результат:

```
Python
P
```

## 3. Различие между числом и его текстовой записью

Число `25` и строка `"25"` отличаются типом данных.

С числом можно выполнять математические операции, а строка представляет собой текст.

Пример:

```
number = 25
text = "25"

print(number + 5)
print(text + "5")
```

Результат:

```
30
255
```
