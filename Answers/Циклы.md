## 1. Определение

Циклы используются для многократного выполнения определённого блока команд.

В Python существуют два основных вида циклов:

- `for` — перебирает элементы последовательности.
    
- `while` — повторяет действия, пока условие истинно.
    

## 2. Цикл for

Пример:

```
numbers = [1, 2, 3]

for number in numbers:
    print(number)
```

Результат:

```
1
2
3
```

Цикл `for` последовательно перебирает элементы списка.

## 3. Цикл while

Пример:

```
number = 1

while number <= 3:
    print(number)
    number += 1
```

Результат:

```
1
2
3
```

Цикл `while` выполняется до тех пор, пока условие остаётся истинным.
