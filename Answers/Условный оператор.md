## 1. Определение

Условный оператор используется для выбора действий программы в зависимости от выполнения определённого условия.

В Python для этого используются конструкции `if`, `elif` и `else`.

## 2. Принцип работы

- `if` проверяет основное условие.
    
- `elif` проверяет дополнительное условие.
    
- `else` выполняется, если предыдущие условия не выполнились.
    

## 3. Пример

```
number = 10

if number > 0:
    print("Положительное число")
elif number < 0:
    print("Отрицательное число")
else:
    print("Ноль")
```

Результат:

```
Положительное число
```
