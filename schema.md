# Схема базы знаний ExamPrep

## 1. Общие свойства заметок

Каждая заметка должна содержать три обязательных свойства:

- `type` — тип заметки.
    
- `status` — состояние готовности.
    
- `owner` — ответственный за содержание.
    

## 2. Типы заметок

|Значение|Описание|
|---|---|
|answer|Ответ на экзаменационный вопрос|
|term|Общее определение термина|

## 3. Статусы

|Значение|Описание|
|---|---|
|draft|Черновик, находится в разработке|
|review|Передан на проверку|
|approved|Проверен и одобрен|

## 4. Ответственные

В поле `owner` указывается имя участника, ответственного за содержание заметки.

Имена должны записываться одинаково во всех файлах.

## 5. Правила проверки

- Автор самостоятельно готовит ответ.
    
- Другой участник проверяет правильность объяснения.
    
- Проверяются все внутренние ссылки.
    
- Проверяется соответствие ответа общим определениям.
    
- После устранения замечаний статус меняется на `approved`.
    

## 6. Правила ссылок

Для связи заметок используется синтаксис Obsidian:

`[[Название заметки]]`

Каждый общий термин должен иметь одну основную заметку в папке Terms.

Копировать определения в экзаменационные ответы не нужно. Вместо этого используются ссылки на общий словарь.
