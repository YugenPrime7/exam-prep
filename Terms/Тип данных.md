## Определение

Тип данных — это характеристика значения, определяющая, какую информацию оно хранит, какие операции с ним можно выполнять и какие значения оно может принимать.

## Пример

В Python:

- `int` — целые числа.
    
- `float` — числа с плавающей точкой.
    
- `str` — текстовые строки.
    
- `bool` — логические значения `True` и `False`.
    

```
age = 18
price = 12.5
name = "Alex"
```

В данном примере переменные содержат значения разных типов.
