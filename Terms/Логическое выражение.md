## Определение

Логическое выражение — это выражение, результатом вычисления которого является логическое значение True или False.

Оно используется для проверки условий и выбора дальнейших действий программы.

## Пример

```
age = 18

print(age >= 18)
```

Результат:

```
True
```

Выражение `age >= 18` проверяет, достиг ли возраст значения 18.
