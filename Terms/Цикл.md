## Определение

Цикл — повторение блока действий.

## Пример

```
for number in [1, 2, 3]:
    print(number)
```

Программа последовательно выводит элементы списка.

## Дополнение

Циклы применяются для повторения действий и обработки последовательностей данных. Основные виды циклов в Python - for и while.
