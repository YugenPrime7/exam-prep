## 1. Общая карта материалов

Эта карта объединяет все экзаменационные вопросы по программированию и показывает связи между ними.

### Часть 1. Работа с данными

- [[Тип данных]] — общий словарь типов данных.
    
- [[Числовые типы данных]] — изучение целых и дробных чисел.
    
- [[Списки и строки]] — хранение нескольких значений и текстовой информации.
    

Сначала необходимо изучить типы данных, чтобы понимать, какие значения используются в программах и как они хранятся.

### Часть 2. Управление программой

- [[Логическое выражение]] — проверка условий.
    
- [[Условный оператор]] — выбор действий в зависимости от условия.
    
- [[Цикл]] — общее определение повторения действий.
    
- [[Циклы]] — изучение конструкций for и while.
    

Условные операторы и циклы являются основными конструкциями для управления выполнением программы.

### Часть 3. Решение задач

- [[Сумма положительных чисел]]
    
- [[Подсчёт подходящих элементов]]
    

Эти задачи объединяют изученные ранее темы.

## 3. Связи между материалами

Перед решением задачи о сумме положительных чисел необходимо понять, какие числовые типы используются для хранения элементов и суммы.

Затем нужно изучить логические выражения, чтобы правильно проверять положительность числа.

После этого изучаются циклы, которые позволяют перебрать каждый элемент списка.

В итоге все три темы объединяются в задаче [[Сумма положительных чисел]].

Задача [[Подсчёт подходящих элементов]] использует аналогичный принцип: перебор элементов и проверку заданного условия.

## 4. Общие термины

Все определения хранятся централизованно в папке Terms:

Использование общего словаря помогает избежать дублирования определений и поддерживать согласованность материалов.

## 5. Проверка связей

Для проверки необходимо:

1. Открыть один из экзаменационных ответов.
    
2. Перейти по ссылке на общий термин.
    
3. Открыть Backlinks.
    
4. Проверить, какие заметки ссылаются на этот термин.
    
5. Вернуться к карте содержания.
    

Особенно важно проверить, что [[Циклы]] и [[Сумма положительных чисел]] ссылаются на общий термин [[Цикл]].
